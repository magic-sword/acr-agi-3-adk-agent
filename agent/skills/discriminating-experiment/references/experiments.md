# Useful and useless discriminators

Question: does UP move the marked object north or west? Both explanations predict a changed frame, so true versus false `frame_changed` does not test this question. Predict distinct observed locations using grounded facts or cells whose colors are known. First check collisions: if both candidate paths are blocked, unchanged output still cannot distinguish the mappings.

Question: is a button responsive at all? Changed versus unchanged frame can be a preliminary discriminator if no unrelated animation changes the screen. A changed status counter establishes responsiveness but not object motion or goal progress.

Question: does a switch open a gate? Pressing the switch and touching the gate before inspecting it confounds two interventions. Prefer one action followed by inspection; if opening is delayed, preserve the uncertainty introduced by each time-advancing action.

Outcomes can match both alternatives or neither. Record such results as inconclusive. Distinct JSON arrays alone do not make a scientifically useful experiment; the predicted observations must differ in a visible region under the tested conditions.
