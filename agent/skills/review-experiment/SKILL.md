---
name: review-experiment
description: Compare a frozen prediction with actual observations and update a scoped hypothesis and subgoal.
---

Read active_experiment. If review_request is present, a previous host measurement already
fixed the verdict: preserve it and reconsider the subgoal and next intervention. Compare its predeclared expectation with BEFORE and CURRENT, the
issued action and actual experience. Cite that experience ID. supported means the expected
observation occurred, not that causation or the full game rule is proved. unsupported means
it did not occur within the declared conditions and observation window. Use inconclusive
when the images cannot distinguish the prediction, the target was ambiguous, or evidence
is missing. A change elsewhere is not support for the selected target's response.

State the concrete finding and a short update for the next design job. Assess the subgoal's
own done_when separately: a negative answer can complete a knowledge question without
making game progress. Do not rewrite the original prediction, choose a new action or treat
a failed test as a permanent coordinate ban. Record which condition or explanation should
be reconsidered; only the next design job chooses the next experiment.

Fill understanding with reconsider_assumption, open_question and subgoal_reason. First check
the actual action coordinates against the intended target and the observation scope against
the predicted effect. A one-pixel non-change is not proof that an entire object has no effect.
Distinguish observations from possible explanations (missed target, unobserved remote effect,
missing prerequisite, or a wrong rule). Keep unverified explanations uncertain. Select the
most useful remaining question instead of saying only "try something different". Justify
continuing, completing or abandoning the subgoal against its original completion condition.
