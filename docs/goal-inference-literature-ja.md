# ゴールの推定に関する先行研究（2026-09-30）

問い：ゴールの仮説をどう出すか。一般的な知識をあらかじめ列挙する方法で、ゲームの形式が大きく変わる ARC-AGI-3 を表しきれるのか。背景は [goal-pipeline-ja.md](goal-pipeline-ja.md)（Qwen 4B が ls20 で出した35個の仮説に、正解が0個だった）。

## 1. ARC-AGI-3 自体の設計（技術報告）

- エージェントには目的も説明も与えられず、勝利条件を含めて自分で推定しなければならない。報告は「ゴール設定」を「明示的な指示なしに、望ましい将来の状態を見つける能力」と定義している。
- ゲームは、コア知識（物体性、基本的な幾何・位相、直観的な物理、エージェント性）だけで作られ、言語や文化的な記号は使わない。
- 一方で、**多様さを設計上強制している**。単一の仕組みを大きさや難しさだけ変えた環境は「避けるべき型」とされ、各環境は複数の仕組みを持つ。さらに、「1つのプログラムで2つの環境を解くには、少なくとも50%長いプログラムが必要」という新規性の検査がある。
- プレビュー大会の上位は、総当たりに近い探索だった（1位は、盤面が変化する操作を CNN で予測する強化学習で12.58%）。最先端の LLM は1%未満。

→ **固定のゴールの型を列挙して当てはめる方法は、この設計（型の再利用を不利にする新規性の検査）と正面から衝突する。** コア知識は語彙（物体、位置、接触など）としては共通だが、ゴールの組み立て方はゲームごとに新しい。

## 2. ゴールを明示的に推定しない、系統的な探索

- **Graph-Based Exploration for ARC-AGI-3**（Rudakov ら 2025）
  - 盤面を同色の連結成分に分け、状態のハッシュで有向グラフを作り、まだ試していない「状態×操作」への最短経路をたどって系統的に探索する。
  - 操作は見た目の目立ちやすさ（大きさ、形、色）で優先度を付け、ステータスバーは最後に回す。
  - **ゴールは一切推定しない。** それでも6ゲーム52レベル中、中央値30レベルを解き、非公開のリーダーボードで3位。LLM ベースのエージェントを大きく上回った。
  - ただし大量の手数を使う（評価の上限は1ゲーム最大96,000手）。ARC-AGI-3 の成績はレベル数が主で、手数は同点時の比較に使われる。
  - この論文は、ls20 のレベル1が「形を変える物体で鍵の形を合わせ、出口の扉を開ける」ものだと述べている。これは私たちが V2 でソースから読んだ条件と一致する。
- Go-Explore（Ecoffet ら 2021）：到達した状態を保存し、そこへ戻ってから探索する。報酬がまれな問題で有効。

→ ARC-AGI-3 で唯一の信号は「レベルの完了」である。そのため、**探索でレベルの完了にたどり着くこと自体が、ゴールを知る最も確実な方法**になっている。

## 3. ゴールを推定する方法

- **Twin**（2026、ARC-AGI-3）：クリアしたレベルの87.2%で、報酬を得る前にゴールを推定できた。残りは探索で見つけた。「世界モデルを作るのは思ったより易しく、難しいのは正しいゴールの推定」と結論している。ただし大規模なモデルを使っており、推定の詳しい手順は要旨からは分からない。
- **EMPA / Theory-based RL**（Tsividis ら 2021）：ゴール（終了条件）も「理論」の一部としてベイズ推論で仮説を持ち、試行で確かめる。
- **逆計画によるゴールの推定**（Baker, Saxe & Tenenbaum 2009）：合理的に行動する他者の行動から、その目的を逆算する。ARC-AGI-3 には手本の行動はないが、「レベルが完了した瞬間に何が成立したか」という結果から、ゴールを逆算する考え方は使える（私たちの V2 と同じ）。

## 4. 人間がゲームで使う事前知識

- **Investigating Human Priors for Playing Video Games**（Dubey ら 2018）：ゲームの見た目から事前知識の手がかり（物体の意味、見た目の一貫性など）を消すと、人間がゲームを解く時間は2分から20分以上に延びた。**最も重要なのは「物体」という一般的な事前知識**で、特定の意味（梯子や鍵）より効く。

→ 人間の直感の中心は、個々のゴールの型ではなく、「物体がまとまって動く」「見た目が同じものは同じ種類」といった、探索の方向づけに使う一般的な知識である。

## 5. 何を試すかを LLM に選ばせる研究

- **OMNI / OMNI-EPIC**（Zhang, Lehman, Stanley, Clune）：LLM が人間の「面白さ」の感覚を持っていることを使い、次に取り組む課題を選ばせる（ゴールの推定ではなく、探索の優先順位づけ）。
- **自己目的的なエージェント**（autotelic agents、Colas ら）：自分でゴールを生成し、到達を練習することで世界を学ぶ。

## 6. この計画への示唆

1. **ゴールの型を網羅的に列挙する方向はとらない。** ARC-AGI-3 の新規性の設計と衝突する。
2. **系統的な探索を土台にする。** グラフ探索の論文が示すように、ゴールを知らなくても、状態と未試行の操作を記録して系統的に探索すれば、多くのレベルに届く。私たちの規則の学習（予測・照合・修正）は、この探索の効率を上げる部品になる。
3. **Qwen の仮説は「決め打ちの目標」ではなく、「探索の優先順位」として使う**（OMNI の考え方）。仮説が外れても探索は止まらず、仮説が当たれば手数を大きく減らせる。今の実装では、仮説が悪いと「何を試すか」の繰り返しに陥るので、この点を変える必要がある。
4. **ゴールを最も確実に学べるのは、レベルの完了の瞬間**（逆計画、Twin、V2）。完了したときに成立した関係を記録し、同じゲームの次のレベルの最有力の仮説にする（実装済みの持ち越しを強化する）。
5. **手数の予算**：グラフ探索は大量の手数を使う。私たちの設定（1ゲーム600秒）では、新方式で1手0.5〜6秒なので、100〜1,000手程度になる。探索の土台と、仮説による優先順位づけの組み合わせで、この予算に収める必要がある。
