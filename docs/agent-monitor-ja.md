# JupyterLabでベンチマークの記録を再生する

[観測用ノートブック](../notebooks/agent_observatory.ipynb)は保存済みベンチマークの再生専用。ゲーム画面、選択した操作、DECIDE / RUN、各状態の入出力を同じ時点で確認する。

## 使い方

1. ターミナルで`make benchmark`を実行する。結果は`outputs/evaluations/<評価ID>/`に保存される。
2. JupyterLabでノートブックを開き、上から実行する。
3. **評価ID**のプルダウンでベンチマークを選ぶ。
4. **ゲーム**のプルダウンで記録を選び、**読み込む**を押す。
5. ▶で再生。前へ／次へ、スライダーでも移動できる。

以前のライブ表示を開いたカーネルでは、一度 **Kernel → Restart Kernel and Clear Outputs** を実行してから使う。以前の自動更新処理がカーネル内に残るのを避けるため。

既定は「操作」単位。細かい状態遷移やツール呼出しを見るときは「イベント」へ切り替える。再生間隔は表示用であり、実行にかかった時間とは異なる。新しい評価が終わったら**評価一覧を更新**する。

一覧には状態ログとゲームのresult.jsonがある記録を表示する。中断・失敗した評価でも、結果ファイルが保存されていれば選べる。読み込むのは選択したゲームだけ。状態ログのない旧形式への変換は行わない。

## 表示内容

- **前後の画面と操作**：赤丸はその画面に対して選択したクリック位置。選択のみ・送信・受付・次観測の有無を分ける。
- **状態・課題・予測・画面差分**：DECIDE / RUNと処理中／完了、保持している課題や認識メモ、操作前の予測を表示する。
- **状態の入力／出力**：作業記憶、前回結果、選んだ仕事、処理結果やエラー。出力前なら、その時点ではまだ記録されていないと表示する。
- **HTTP入力／モデル応答・ツール／学習**：各記録のstepと時刻を確認できる。スキルのロード、引数、成功／失敗、候補作成・評価も対象。
- **記録済みアニメーション**：その観測に付属する遷移の途中フレームをスライダーで確認する。

詳細を開くと再生は一時停止する。▶で再開すると詳細を閉じる。モデルの出力は記録として表示し、内部思考を推測して補うことはしない。画面変化や操作受付は、予測の的中や攻略の成功とは別である。

## 軽量化した処理

ノートブックからの評価起動・ライブ追従・バックグラウンドのポーリングを削除した。アイドル時は処理しない。

評価IDの一覧取得はベンチマークの浅いディレクトリ構造だけを調べ、画像・ソースのツリーを再帰走査しない。読み込み時に一度だけイベント順の索引を作り、シーク時に過去の全イベントを再計算しない。

画像は同じ観測・操作の間は再生成しない。色IDグリッドも多数のSVGセルではなくPNGに変換する。大きな入力・出力ログと途中フレームは詳細を開いたときだけ画面へ送る。再生中に隠れた全パネルを更新しない。

## 記録

`<run>.states.jsonl`に状態の入場・退出と入力／出力を保存し、全ジャーナル共通の`sequence`で並べる。観測画像、実行受付、モデル要求・応答、ツール・学習イベントを同じ走行IDで対応づける。

読み込み後は記録を固定して再生する。ディスクへの追記を自動では取り込まない。途中で止まったJSONLの未完了行は除外し、未来の状態出力や観測を表示位置へ混ぜない。

## File Load Errorの場合

`Unhandled error`だけでは原因を判別できないため、`docker compose logs dev`を確認する。今回の環境ではノートブック取得がHTTP 200でもチェックポイント作成がHTTP 500になっていた。原因は`notebooks/.ipynb_checkpoints`の所有者とJupyter実行ユーザーの不一致。修正済みで、`make repair-perms`にもチェックポイントを含めた。

ノートブックのJSON検証やカーネル実行だけでは、このブラウザ経由の保存処理は検証できない。

## 確認結果

回帰テスト54件と、Jupyterカーネルでのノートブック実行・選択読込みを確認した。30操作の保存記録（426イベント、最終観測を含む31ステップ）では、読込み約17ms、イベント移動のPython処理は中央値約0.12msだった。これはカーネル側の測定で、ブラウザ描画・通信時間は含まない。

全イベントの移動中、隠れている詳細パネルの更新は0件。画像の値が実際に更新されたのは13回で、更新されたPNGデータの合計は約92KBだった。測定記録は`outputs/replay-validation/measurement.json`、実行したノートブックは同ディレクトリの`executed.ipynb`に保存した。
