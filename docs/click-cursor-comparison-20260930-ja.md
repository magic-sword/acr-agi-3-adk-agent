# 削除前の高速カーソル処理との比較（2026-09-30）

旧処理の単独照準では18対象中5件（27.8%）が命中し、同時に再測定した全候補マスク方式の13件（72.2%）を下回った。64回で打ち切った5問を45秒相当まで延長しても命中数は変わらなかった。

## 再現した範囲

削除直前のコミット `46ac1b2` から `agent/cognition/cursor.py` と `tasks.py` の `aim_locate` / `aim` 指示文を取得した。カーソル開始位置、4分割の領域選択、上下左右の移動、移動幅の半減・倍増、拡大表示、7によるクリック確定は旧コードをそのまま使用した。描画依存の `agent/rendering.py` も当該コミットから変更がないことを確認した。

正しい対象説明を与えた照準部分の単独試験である。旧ランタイム全体を復元した試走ではない。計画・記憶・場面仮説・計測一覧は与えていない。8は再検討として終了し、その後の再計画は実行しない。本番コードに旧処理を戻してはいない。

これまでと同じ実画面3枚・合成8画像の26問を使用。一意な対象18問（実画面12・合成6）、曖昧・不存在の8問。正解ピクセル注釈は以前に固定したもの。カーソルはマスクを返さないため、主比較は領域正解率ではなく「明示的に確定したクリック点が正解注釈内にある割合」。ゲーム内部のクリック判定・攻略進展は未検証である。

モデルは同じローカル qwen3-vl-4b-instruct、temperature=0、1トークン選択。旧 `fast_choice.py` に合わせてカーソル側は `cache_prompt=True`、logprobs有効。従来のマスク比較はcache無効なので、所要時間はアルゴリズムだけを揃えた厳密比較ではない。精度とループの有無を主に見る。

## 実験予算

最初は各問45秒または64呼び出しの早い方で止めた。64回で止まった5問については、その結果を見た後の追加確認として、同じ状態から合計45秒の実処理時間まで継続した。継続段階には呼び出し回数上限や反復状態での早期停止を置かない。初回の応答・集計は保存し、追加結果は別ファイルにする。これは予算感度の確認であり、全問を最初から連続で再実行するものではない。

## 64呼び出し上限での比較

全候補マスク方式も今回のサーバーで26問を再測定した。命中・不命中は前回の順序0と全問一致した。ページ方式の値は前回の保存結果を参照する。

| 方式 | 全18対象への命中 | 実画面12対象への命中 | 合成6対象への命中 |
|---|---:|---:|---:|
| 全候補マスク選択＋マスク内点（今回再測定） | 13/18（72.2%） | 8/12（66.7%） | 5/6 |
| ページ分割＋文字＋マスク内点（前回） | 15/18（83.3%） | 9/12（75.0%） | 6/6 |
| 旧高速カーソル（今回） | 5/18（27.8%） | 2/12（16.7%） | 3/6 |

旧カーソルは全候補マスク方式より **44.4ポイント低く**、実画面だけでは **50.0ポイント低かった**。ページ方式との差は全体で55.6ポイント。ただしマスク方式の命中には、対象の一部分・過大な領域を選んで点だけ当たる例も含まれる。領域理解が正しいことまでは保証しない。

旧カーソルは一意18対象のうち14件でクリックを確定したが、9件は対象外。残り4件は64回上限に達した。否定8問は正しく再検討4件、誤クリック3件、上限到達1件。ループでクリックしなかった1件を「正しく棄却」とは数えない。

対象あり問題の時間中央値は旧カーソル1.59秒、全候補マスク方式0.558秒。旧カーソルは全26問で381呼び出し。中央値は短くても、5問が64呼び出しを使い、各約11〜12秒まで続いた。

## 観察した失敗

- ft09 左上青タイルでは `(8,0)` と `(0,0)` の左右往復が続いた。
- vc33 の棒では `(39,15)` と `(47,15)` の左右往復が続いた。
- 26問中7問で同じ位置・移動幅の状態を再訪。再訪自体をすべて失敗とは扱わず、上限到達5問と区別した。
- 命中5件中4件は、4分割の領域を選んだ直後の中心点をそのまま確定したもの。移動によって命中したのは合成画像の1件だけだった。
- ft09 の上下の模様は `(15,15)` / `(47,47)` に即確定して命中した。これは微調整の有効性を示す例ではない。

## 45秒相当までの追加確認

初回に64回で打ち切った5問を同じ状態から継続した。結果は以下の通り。

| 対象 | 追加確認後 | 合計呼び出し数 |
|---|---|---:|
| ft09 左上青タイル | 45秒上限、未確定 | 272 |
| ft09 曖昧な対象 | 45秒上限、未確定 | 248 |
| vc33 棒全体 | 45秒上限、未確定 | 256 |
| vc33 上側青対象 | 対象外でクリック確定 | 76 |
| vc33 下側青対象 | 対象外でクリック確定 | 72 |

**延長後も命中は5/18で、精度差は変わらなかった。** 5問すべてが永久ループだったわけではなく、2問は後で確定したものの誤った座標だった。残る3問は45秒相当で未確定。一意18対象では16件確定・うち11件対象外、2件未確定となった。

追加604呼び出し、初回と合わせてカーソル985呼び出し。全候補方式再測定26呼び出しを含め、今回の総数は1011。追加要求のハッシュを照合し、サーバー設定も変わっていないことを確認した。関連テストは9件成功。

## 判断

この固定データでは、旧高速カーソルをそのまま戻すと精度が上がるという根拠は得られていない。誤ったクリック確定と往復の反復が両方残る。

「マスク内点から開始し、最大1回だけ補正する」方式は今回とは別であり未検証。旧カーソルの4分割中心からの探索結果を、そのような限定補正の結果に読み替えてはいけない。
