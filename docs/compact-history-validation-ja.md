# 操作履歴の重要な観測への絞り込み

> この資料の速度計測は単一操作版の実験結果。計画と抽象操作の高速実行は[復元済み](planning-restoration-ja.md)であり、現在の通常経路は `FocusedRuntime`。履歴軽量化とマスク内クリックは維持する。

2026-09-29。通常の `SimpleRuntime` の履歴保存時に、全対象の観測結果をそのまま蓄積する方式を変更した。

- 計画で指定した対象：変化0も含めて保存。対応状態、操作前マスクへのクリック命中、画素変化数、移動量を保持する。
- 別の対象：画素変化または移動が実測されたものだけ保存。無関係な対象の無変化を操作履歴に入れない。
- 計画対象の測定がない場合：`unmeasured` と `null` を記録し、無変化0とは区別する。
- 各対象に繰り返し付いていた観測ID・定型説明を省き、解釈上の注意は入力全体に1回だけ渡す。
- 履歴の対象スナップショットもID・同一性区間・位置・色だけにする。操作、受付、盤面全体の変化数、予測、疑問、モデルの条件付き解釈は維持する。

モデルに渡す直近4試行・保持する16試行の件数は変更していない。認識処理そのものの対象索引や観測ログは別であり、操作履歴と混同しない。対象マスク上の画素変化は因果関係やゲーム上の効果を証明しない。
