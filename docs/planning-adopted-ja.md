# 行動計画の現在の採用方針

更新：2026-09-29。実行時間の制約を優先し、通常経路は**1回のモデル判断で直前の結果を解釈し、次の1操作を選ぶ**方式へ統一した。現在の構成・検証・未解決点は[引き継ぎ資料](visual-recognition-handoff-ja.md)を参照する。

## モデルに渡すもの

現在画像（測定上の条件で省略する場合がある）、現在の対象索引と使える操作、直近4試行の重要な観測。試行は、対象に何をしたか、その対象が変化・無変化・未測定のどれだったか、別対象に実測変化があったかを記録する。無関係な対象の無変化を並べない。

## モデルが返すもの

前回の結果の条件付き解釈、今回確かめる疑問、次の1操作と対象ID、期待する効果。モデルが別工程への戻りを選ぶフィールドはない。クリック座標は現在の対象マスク内からホストが決める。対象・操作が不明なら無理に捏造せず、契約検証または使用可能な対象の有無で止める。

## ホストが保証するもの

現在の観測ID、使用可能な操作、現在の対象マスク、受付と次の観測、冪等性、ゲーム終了と時間・操作上限。出力契約の修正だけ最大1回許す。画素変化・対象対応・因果解釈は別物として保持し、1回の結果で一般的な法則を確定しない。

多段の逆算計画、暫定候補生成器、毎操作の高速判断、照準調整、独立した結果照合、ノート巡回、旧比較ランタイムは削除した。
