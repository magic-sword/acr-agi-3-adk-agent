# 動きの可視化による認識補助：先行研究と次の比較候補

> 調査履歴：この資料は個別実験時点の記録です。現在の採用方針・主要な検証結果・参考文献は[統合資料](visual-recognition-adopted-ja.md)を参照してください。本文中の提案は、そのまま現行方針を表すものではありません。

調査日：2026-09-28。今回は文献調査であり、新しいQwen測定は実施していない。

## 結論

追加学習なしのQwenでも、動きを画像上で明示して認識を改善した報告がある。ただし、半透明の残像を増やすこと自体を支持する結果ではない。現状のゲームでは「元の姿を保ち、時間的な違いを少数の注釈で示す」加工を優先して比較する根拠になる。

## 直接参考になる研究

### Motion-as-Prompt（2026年8月、査読中プレプリント）

点追跡器CoTracker3で動画から軌跡を取り、選択した前フレームから現フレームまでの線と終点マーカーを、現フレーム上に描く。Qwen自体は追加学習しない。

- Qwen3-VL-2B、CLEVRER平均：57.6 → 60.4%。移動物体の属性：76.0 → 79.5%。
- 軌跡描画だけの寄与は平均で+1.8ポイント。残り+1.0ポイントは動きに基づくフレーム選択。総改善を描画だけの効果としない。
- 高頻度の元動画から情報を取り出す方式。今回の前後2枚だけの入力と同条件ではない。
- 追跡点の選別閾値は画像幅の3%。64画素幅に換算すると1.92画素なので、単純移植すると1画素移動を除外してしまう。

出典：[論文・表1、§3.4、§4.5](https://arxiv.org/html/2608.11655v1)。

### MotionSight（2025）

物体領域を時間方向に安定化させ、その位置と外観を保持しながら周囲を暗くするVisual Spotlightを使用。追加学習を行う別提案MotionChatとは区別する。

Qwen2.5-VL-7B、MotionBenchの物体運動平均は、元入力51.7、Spotlight53.0、背景ぼかし49.3、物体のモーションブラー50.2。全体のモーションブラーはカメラ運動で34.0 → 48.3だが、物体運動では50.8だった。重ね合わせ・ぼかしの適性は対象タスクで異なる。

出典：[論文・§3、表6](https://arxiv.org/html/2506.01674)。

### Dynamic Image Networks（CVPR 2016）

動画の時間順序をrank poolingで1枚へ圧縮する。UCF101の単一画像表現の比較では、平均画像52.6%、Dynamic Image57.9%。ただしCNNをその表現で学習・評価した結果で、加工画像を既存Qwenに渡すだけの効果ではない。

出典：[論文・§4.2–4.3、表1](https://www.cv-foundation.org/openaccess/content_cvpr_2016/papers/Bilen_Dynamic_Image_Networks_CVPR_2016_paper.pdf)。

## 今回のゲームへの適用案（文献からの推論・未測定）

[前回比較](temporal-overlay-comparison-20260928-ja.md)では境界線付きが有望だったが、微小な二色ブロック移動や逆方向の複数対象移動は未解決。暗色化・境界色をゲーム内の変化として読む誤りも残った。

次の比較は、元のBEFORE・AFTERを共通に渡し、3枚目だけを替える。画像サイズ、入力枚数、質問、事前物体一覧を揃える。

| 条件 | 加工 | 確認したいこと |
|---|---|---|
| 基準 | 前回の半透明＋前後境界、背景明度70% | 既存結果との接続 |
| A | 基準の背景明度だけ100%に戻す | 暗色化に由来する誤認を減らせるか |
| B | 原色AFTER＋前後で異なる境界線。半透明混合なし、背景明度100% | 混合色を除き、対象の姿を保持すると認識しやすいか |
| C | 同じ固定範囲から切り出した前後画像を、同倍率で隣接拡大 | 1画素変化の見やすさを上げるだけでも改善するか |

BはMaPそのものの再現ではなく、現在像と時間的注釈を共存させる発想からの応用。Cも研究で直接検証された今回の設定ではない。拡大範囲には対象全体と近傍の目印を含め、前後で対象を別々に中央寄せしない。差分のまとまりを、そのまま一個の物体と断定しない。

実際の連続フレームを利用できる場合は、その後に「短い追跡線＋終点」を追加候補とする。線は前処理で物体対応を仮定するため、対応を検証できない箇所を無理につながない。回転や連動する部品を同方向移動という条件でまとめない。前後2枚から観測されていない経路を生成しない。

Qwenへの要求は「何が動いたか」「移動・変色・変形のどれか」のままでよい。描画の内部計算で座標を使うことと、Qwenに正確な座標を答えさせることは別である。

評価には1・2画素移動、複数対象の逆方向移動、白い対象、変色のみ、変形、無変化を含める。移動対象の認識率に加え、加工を実物の変化と読む誤りを測る。ゲームのルールや対象の役割を正解として入力へ埋め込まない。

## 根拠の範囲

先行研究は今回のQwen3-VL-4B量子化モデル・64×64ピクセルゲームにおける最適加工を決めるものではない。また、画像上の動きの認識改善だけでは、その動きが操作によるものかという因果関係まで確定しない。前回の小規模比較と今回の文献は、次に比較する加工を選ぶための根拠として扱う。
