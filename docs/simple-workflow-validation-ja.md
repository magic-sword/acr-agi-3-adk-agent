# 通常経路の単純化

2026-09-29。既定ランタイムを `SimpleRuntime` に変更した。

## 実行経路

```text
観測・対象マスク・直前の受付済み結果
  → モデル1回：結果の条件付き解釈＋今回の疑問＋次の1操作
  → ホスト：操作可否と対象IDを検証、マスク内のクリック座標を計算
  → 操作送信
  → 次の観測
```

1〜2操作の短い検証のうち、まず1操作ずつに固定した。通常の理解・逆算・候補生成・具体化・高速継続判断・カーソル調整・独立した結果照合は呼ばない。前回結果の解釈と次の選択を同じ要求で行う。出力契約違反の修正は既存設定の最大1回のみ残る。

ゲーム終了、受付不明、使用不可操作、期限・操作上限は従来のホスト検査で止める。クリックしか使えず現在マスクがない場合は `no_grounded_action` で停止する。対象を捏造したり、古い座標でクリックしたりするフォールバックは設けない。

クリックはモデルが現在の対象IDを選び、ホストがマスク重心に最も近いマスク内画素を選ぶ。穴のあるマスクでも穴には置かない。これは認識マスク内への命中であり、ゲーム上の有効な作動点や物理的な対象同一性まで保証しない。

対象ID、操作前の対象スナップショット、受付と実測結果、条件付き解釈を保存する。モデル入力には直近4試行の要約を渡し、履歴のマスク自体は渡さない。レベル・リセット境界で試行履歴を消去する。長期的な法則や再利用スキルの学習はこの簡略経路では行わない。

後続変更として、履歴保存時点で「計画対象の結果（無変化・不明を含む）」と「別対象の実測された変化」に絞った。無関係な無変化や対象ごとの重複説明は蓄積しない。[履歴軽量化の検証](compact-history-validation-ja.md)を参照。

後続の整理で旧 `FocusedRuntime` と比較用設定、候補生成器注入を廃止した。現行は `SimpleRuntime` のみで、旧クラスへの継承依存も削除した。[削除一覧](history/runtime/retired-implementation-ja.md)を参照。

## 検証

単体テストで1操作1モデル判断、無変化の受付済み観測の引き渡し、同一観測の再要求でモデルを再実行しないこと、マスク内クリック、穴の回避、対象不明・使用不可操作の拒否、クリック候補なしのモデル呼び出しなし停止、受付不明の次判断前停止を確認する。

初回試走：`outputs/simple-workflow-20260929/runtime/`。vc33、SAM CPU、判断100秒、全体180秒、操作上限4回。76.4秒で4操作、モデル判断4回、クリア0。高速実行判断・カーソル調整は0回。黒い棒と黄色い対象のマスク内をクリックした。同じ対象を繰り返す選択は残り、法則発見・攻略性能の改善を示すものではない。

この初回試走後に履歴のマスクをモデル入力から除き、遷移図・工程別集計を新経路に対応させた。最終ソースの試走は `outputs/simple-workflow-20260929/final/` に保存する。CPU SAM初期化を含む総時間とモデル判断時間を区別して評価する。

最終版の全296テストは成功（`outputs/simple-workflow-20260929/tests.log`）。最終試走は68.9秒、4操作、4モデル判断、クリア0、操作上限到達で終了した。内訳は初回SAM CPU処理36.79秒、4回のモデル判断合計31.39秒。高速判断・照準調整・独立した結果照合のモデル呼び出しは0回。4回とも選択対象の操作前マスクへの命中をホスト記録で確認した。

同じ対象の反復は残る。マスク内への命中と法則発見は別であり、現時点で確認したのは通常経路の呼び出し削減と4操作までの進行である。両試走は単一ゲームの短い実行で、汎用的な攻略性能や速度比を保証しない。
