# 物体ごとの階層クイズ比較（2026-09-28）

> 調査履歴：この資料は個別実験時点の記録です。現在の採用方針・主要な検証結果・参考文献は[統合資料](../../visual-recognition-adopted-ja.md)を参照してください。本文中の提案は、そのまま現行方針を表すものではありません。

「変化したか？」を入口にすることで、質問数は261問から124問（52.5%減）、リクエスト時間の合計は38.63秒から19.66秒（49.1%減）になった。ただし、変化のある36候補のうち6候補を入口で「変化なし」と判定し、詳細確認を飛ばした。網羅性を維持できたという結果ではない。

今回の少数の変化分類では、「変化なし」を含めた直接分類が、階層方式と全候補で同一の最終回答を87問で出した。プログラムの測定値で入口を判定すると43問まで減るが、後段のQwenが測定上の変化を否定する問題は残った。

[結果ブラウザ](../../../outputs/hierarchical-20260928/gallery.html)では場面・物体候補を選び、4方式の回答、入口判定、呼び出し数、測定状態を確認できる。

- 測定状態の上では、変化あり36、変化なし44、対応未確定7候補。別に、抽出対象外の大きな領域が変化する1場面には400画素の未カバー差分があり、要確認として別途保持した。

## 質問数をどう解釈するか

物体数をN、調べる属性数をK、変化ありの物体数をC、対応不明などで保留する物体数をUとする。

- 全項目を聞く：K×N問。
- 各物体の入口1問＋詳細の組み合わせ1問：正しく振り分けられればN+C+U問。
- 入口の後にK属性を個別に聞く：N+K×(C+U)問。
- 変化なしを含む直接分類：N問。ただし属性数が増えると組み合わせが増え、選択が難しくなる。
- プログラムで入口を測定する：Qwenへの質問はC+U問。

今回なら理想的なQwen入口は87+36+7=130問だが、実測は124問だった。差の6問は見落としによる削減であり、効率改善に数えるべきではない。入口の答えはNoが50件、Yesが37件、不明は0件。不明7件もYes経由で詳細に進み、そこで不明に戻された。

3属性の場合、正しい階層化の削減率は最大でもおおむね3分の2。一方、属性・詳細質問が多数あり、変化する物体が少ない場面では、より大きな削減が期待できる。この一般化は未測定。

## 見落としと解釈上の注意

入口のNoで飛ばした変化6候補は、motion_0_1_T1/b2、motion_0_2_T1/b2、motion_1_1_T1/b2、motion_1_2_T1/b2、motion_3_2_T1/b2、panel_1_T1/b2。詳細まで進んだ候補にも5件の「変化なし」誤答があり、最終的には11/36件を見落とした。

直接分類も同じ11件を見落としており、今回の階層方式が直接分類より最終精度を悪化させたわけではない。一方、全3項目を個別に問う方式の見落としは8件で、質問のまとめ方に精度との交換条件がある。全候補の正解数だけでは、不明の保持が改善したことと変化認識の低下が相殺されるため、変化ありの部分集合を見る必要がある。

プログラム入口には測定上の見落としがなかったが、Qwenの詳細回答が11件を「変化なし」にした。例えばmotion_3_2_T1/b1は、3×3の青い領域の左上が(17,16)から(17,20)へ変わり、大きさは同じ。それでも後段の詳細回答は「変化なし」だった。

詳細質問は各方式で共通にし、入口回答を文面に追加していない。したがって、これは呼び出しの分岐の比較であり、「Yesだったから必ず何らかの変化を選べ」と誘導する追加文の効果は未検証。その誘導だけでは入口の誤判定を引き継ぐ可能性がある。

## 推奨する構成

階層化は質問数削減に有効。ただし入口をQwenのNoだけに任せて候補を捨てる構成は、この結果では推奨しない。

1. 対応が十分確かな候補では、位置・大きさ・パターンの変化はプログラムの測定結果として確定する。
2. 変化なしの候補について、同じ事実をQwenに再確認する質問を省く。
3. 対応不明や抽出外の差分は保留キューへ残す。「不明」や「候補なし」を「変化なし」に置き換えない。
4. Qwenには、変化した候補の役割・操作との関係など、測定だけでは決まらない意味について質問する。測定済みの変化を、後段の自由な回答だけで消さない。

この意味推論に限定する構成や矛盾時の再確認は今回未測定。今回追加したものは比較用スクリプトと閲覧資料であり、本番エージェントの制御は変更していない。

## 検証と限界

ユニットテスト10件、固定した入力・実験コードのハッシュ、全場面からの質問再生成、全1,032応答の1トークン制約、696処理の分岐・呼び出し数・時間の再集計を確認。HTMLは41場面・87候補の切替と画像表示をブラウザで検証した。

これは小規模な合成画面と測定状態のテキスト比較。正解は測定済み候補に関する定義との一致であり、物体分割や前後の同一性がゲームの意味として正しい保証ではない。2回の繰り返しも独立した問題追加ではない。前回の手作り問題に対する27/29正解とは問題形式・対象が異なり、直接比較できない。
