# 不変部分を薄めて差分を強調する表示

> 調査履歴：この資料は個別実験時点の記録です。現在の採用方針・主要な検証結果・参考文献は[統合資料](../../visual-recognition-adopted-ja.md)を参照してください。本文中の提案は、そのまま現行方針を表すものではありません。

**表示と色の保持を確認した段階で、モデルの認識改善は未計測。**

白い対象のコントラスト低下と改善候補について、[視覚的強調の先行研究](change-emphasis-research-20260927-ja.md)を調査した。

使用した観測は、これまで比較したls20の最初のUP前後。

## 方法

前後で色IDが違う画素の位置を、同じ座標のマスクとして両方の画像に適用する。
強調する場所のRGB値は元の値を保持し、それ以外は白と混合する。
既定値は元の色20%・白80%。実際の透明ファイルにはせず、表示背景に依存しない白との合成を用いる。

`強調部分 = 元のRGB`

`それ以外 = round(0.2 × 元のRGB + 0.8 × 255)`

移動前後の位置が両方含まれるため、画像ごとに別の対象を中央に寄せず、
同じ座標・縮尺・マスクで前後を並べる。画素の補間や中間フレーム生成は行わない。
画面全体の原画像も残し、強調表示は加工した補助資料であると区別する。

## 作成した3表示

|表示|原色のまま残す場所|この観測での特徴|
|---|---|---|
|元画像|全画素|静止した十字や上端の図形も確認できる|
|差分画素のみ|色IDが変わった52画素の位置|橙青の移動元と移動先、帯の左端2画素を強調|
|変化した小さな部品まで|上記と、変化が触れた単色連結領域の支持画素。合計134画素|黄色い帯の全体も原色で残る|

3番目は前後それぞれで256画素以下の単色連結領域を調べ、差分画素を含む領域を加える。
形が同じ物体であるという仮定や、Player等の役割を使わない。
大きな背景の全体が強調されることを避けるためサイズ上限を設けている。
この上限は汎用的な物体認識の正解ではなく、比較用のパラメータである。

## 有効性の仮説と注意点

候補番号や座標の文字列を画像の位置へ結び付ける負担を減らし、
変化した場所を原画像の位置のまま詳しく見せられる可能性がある。
前回の[候補選択比較](attention-selection-comparison-20260927-ja.md)では、
候補番号と説明対象の取り違えが残ったため、直接的な視覚手掛かりを試す意味がある。

差分画素だけでは、帯のように一部しか変わらない対象の輪郭は薄くなる。
そのため、ユーザー提案そのものと、部品全体へ強調を広げる派生案の両方を残した。
逆に、派生案の単色領域が一つの物体とは限らず、複数色の大きな物体を十分に含まない場合もある。

白との混合は不変部分の色・コントラストを変える。
静止した参照対象を見落とす可能性があるため、補助表示だけに置き換えない。
また、移動元・移動先の背景画素も変化するため、強調された灰色を別の物体と誤認する可能性がある。
「濃い箇所が操作対象」「動いていない箇所は不要」とは扱わない。
文字情報で発生した上下逆転が、この表示で解消するかは実測が必要。

## 次の比較案

まず、熟考の問い・文字情報・画像枚数・解像度・時間予算を揃え、次の3条件を比較する。

1. 元画像2枚＋元画像2枚の再提示。
2. 元画像2枚＋差分画素だけを強調した前後2枚。
3. 元画像2枚＋変化した小さな部品まで強調した前後2枚。

再提示条件を置くのは、画像枚数と再観察自体の影響を分けるため。
この比較で効果を確認した後、文字の差分情報を外す条件を追加すると、
強調画像だけで対応を読めるかも検証できる。
評価は移動方向、帯の部分変化、不変の参照対象、役割の未確定性、総時間を用いる。
同一画像・色だけの変化・別ゲームも加え、ls20だけで採用を決めない。
