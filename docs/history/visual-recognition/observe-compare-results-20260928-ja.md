# 観測→比較→分類の比較検証（2026-09-28）

> 調査履歴：この資料は個別実験時点の記録です。現在の採用方針・主要な検証結果・参考文献は[統合資料](../../visual-recognition-adopted-ja.md)を参照してください。本文中の提案は、そのまま現行方針を表すものではありません。

**今回の中間文章の誘導では、微小移動の認識改善は確認できなかった。色変化は正しく分類できた一方、実ログの移動や新規出現を見落とす悪化例もあった。** 主測定132件に加え、形式不備を切り分ける補足24件を実行した。

形式を整えた補足比較では、24件すべてが指定形式で回答した。以下は同じ6入力・各環境内での比較であり、少数の選択例の診断結果として読む。

| 実ログls20のブロック移動 | 1/1 | 0/1 | 0/1 | 0/1 |

補足の静止した既知対象への誤検出は全4条件で0/21対象だった。色変化を移動と誤分類する回答は直接判定の両環境で1件ずつあり、観測先行では解消した。ただし、これは同一の色変化画像であり、異なる多数の場面での改善を示すものではない。

## 中間文章から分かったこと

微小移動では、例えば次のような記述になった（公式・二色ブロック1画素移動）。

```text
before: orange and blue stacked blocks centered vertically
after:  orange and blue stacked blocks centered vertically
description: Stacked blocks unchanged in position and appearance
kind: unchanged
```

補足の観測先行では、両環境とも移動対象3件すべてでBEFOREとAFTERの文章が完全一致した。粗い位置と外観なら移動後も同じ説明になり得るため、これ自体が画像を見ていない証明ではない。しかし、**出力した中間文章には判断に必要な位置関係の差が残らなかった**ことは確認できる。

色変化では、前にwhite、後にorangeと書けたことで、比較文と対象分類もcolor_changedに揃った。今回の結果は、「中間文章が正しい差を含めば分類を助ける例がある」一方で、「その文章を書かせる指示だけで微小移動の差を抽出できるとは限らない」ことを示している。中間文章の因果的な寄与を単独で証明する実験ではない。

この指示を移動認識の改善策としてそのまま採用する根拠は得られなかった。次に検証するなら、差分の可視化を実際に入力へ追加し、まず中間文章に正しい差が現れるかを評価する。特徴ベクトルの差は解析側で計算したものであり、今回の文章指示だけではモデルにその差分マップを渡していない。

## 目的と固定条件

前回のXAI診断では、視覚特徴に前後差が残っていても移動を見落とす例があった。そこで、分類語の前に生成する文章を、他物体の判断から対象の前後の観測・比較へ変えると、動いた物体の認識が改善するかを比較した。

主測定は実ログls20の1組と合成10組、各3通りの既存BEFORE物体一覧。通常量子化版と公式BF16版それぞれで直接判定と観測先行を比較し、計132要求、別にウォームアップ4要求を実行した。画像・動画・物体一覧・生成設定は同じ。順序は固定シードで混ぜ、質問と出力項目のみを変更した。

| 方式 | 対象ごとの出力順 |
|---|---|
| 直接判定 | ID → 分類 → 短い視覚的説明 |
| 観測先行 | ID → BEFOREの見た目 → AFTERの見た目 → 一致／相違の説明 → 分類 |

色の配置・形・同じ周辺物との関係・前後で占める場所の違いを確認するよう指示した。変化を前提にせず、同じならunchanged、比較できなければuncertainを許した。正確な座標・方向・距離・ゲーム内の役割は求めていない。正解や特徴差マップはモデルに渡していない。

両方式とも最大1024出力トークン、greedy、JSON文法制約なし。前回の512上限より増やしたのは観測欄のためで、直接判定も同じ上限で再測定した。実際の出力長は同一ではない。BEFOREとAFTERの記述は同じ自己回帰生成の中にあり、「AFTERを改めて観察する」という指示は独立した2回の推論を保証しない。

入力は既存の640×820 RGB画像をA A B Bの4フレーム・4fpsで提示したもの。通常版はllama.cppのQ4_K_M＋Q8_0 projector、公式版はQwen3-VL-4B-Instruct BF16、Transformers 5.0.0、SDPA。両環境の前処理と精度が異なるので、質問の効果は各環境内で比較する。

## 出力形式を明示した補足比較

主測定中、観測先行が最初の対象Aの単独JSONだけを返し、配列と残りの対象を省略する例が見つかった。出力上限への到達ではなく、自発的な終了だった。主測定の指示・結果は変更せず保存した。

これを認識能力と混同しないため、両方式のJSON例に外側の`observations`配列を追加し、全対象を含める指示を再度明示した。以前のXAIで使った合成5例の一覧2と、実ログls20の一覧1を選び、6入力×2方式×2環境＝24要求、別にウォームアップ4要求を追加した。

この補足は形式不備を見てから追加した診断であり、独立した検証用データではない。主測定132件と合算して改善率を算出しない。プロンプトの文法例は直接判定側にも同じように修正し、画像・一覧・1024トークン上限は維持した。

| 有効回答の時間中央値 | 5.41秒 | 8.09秒 | 9.22秒 | — |
| 有効回答の出力トークン中央値 | 202 | 361 | 201 | — |

※全要求を失敗として扱う機械集計では0点だが、全対象を回答していないため物体認識能力の得点としては解釈しない。公式・直接の2無効回答は、分離を説明できた一方で領域Aに許可されない分類値`changed`を使ったもの。

通常・観測先行では、有効回答に含まれた移動対象10件のBEFORE／AFTER記述がすべて同じ文章だった。微小移動の対象はそのうち7件あり、全て見落とした。ls20の一覧2では領域AとFの説明が青橙ブロックの移動を特定したため、個別項目の欠落した対象Xの意味認識を1件回復した。精密な移動量の誤りは採点対象外とした。

有効回答でも実ログls20の認識は直接判定3/3から観測先行1/3へ低下した。したがって、通常版の移動認識低下は形式不備だけでは説明できない。一方、色変化では通常版の一覧0が、前「白い十字」・後「オレンジの十字」・比較「白からオレンジ」・分類`color_changed`と整合した。

両環境の直接判定66回答は、前回の512トークン上限時の回答と全て一致した。主測定の観測先行は早期終了した回答が多く、全回答の時間中央値だけなら約3.3秒になるが、これを高速化とは扱わない。

## 評価上の注意

動いた対象を外観で特定して移動と説明できたかを主評価とした。正確な方向・距離は採点しない。ls20の一覧2は二色ブロックの個別項目が欠けており、領域の説明がそのブロックの移動を特定した場合は、欠落対象Xの意味認識回復として別記する。

無効な出力は主評価では失敗として扱うが、有効回答内での見落としも別に確認する。形式不備で早期終了した回答は短時間なので、実用コストには有効回答の時間・出力長も併記する。前後の文章が同じでも、粗い記述なら画像の細部まで同じことを意味しない。

3通りの物体一覧は独立したゲームや確率的な反復ではない。意味評価は実装担当アシスタントが行い、独立した人間の盲検評価ではない。今回、判断時の注意重みは再計測していないため、認識の変化を注意配分の変化として断定しない。
