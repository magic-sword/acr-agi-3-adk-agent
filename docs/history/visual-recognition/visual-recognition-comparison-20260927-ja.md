# 画面認識の比較結果：部分拡大と根拠付き出力

> 調査履歴：この資料は個別実験時点の記録です。現在の採用方針・主要な検証結果・参考文献は[統合資料](../../visual-recognition-adopted-ja.md)を参照してください。本文中の提案は、そのまま現行方針を表すものではありません。

2026-09-27。[検討案](visual-recognition-research-ja.md)に沿った最初の比較を実施した。
**今回の変更を一括して本体へ採用する根拠は得られなかった。**
部品の記述が増えるケースはあるが、位置の誤記・根拠のない説明も増え、操作後の役割訂正には成功しなかった。

## 条件

- 元ログ：`outputs/history/evaluations/20260926T172310706477Z`。
- 初見：ft09、ls20、vc33の各初期画像。過去の理解・操作結果は空。
- 時間変化：ls20の最初のUP前後。共通の過去理解と受付済み操作・実測差分を与える。
  後続の計画・完了判定・予測文は除く。これは比較用に組んだunderstand要求であり、
  本番reconcileの要求をそのまま再生した結果ではない。
- モデル：Qwen3-VL-4B-Instruct Q4_K_M、画像プロジェクタQ8_0。
  両ファイルのSHA-256が元ログの記録と一致。
- サーバ：llama.cpp b11118-e6ab7c1a4、1枠、文脈長16384。設定は変更していない。
- temperature=0、seed=123、最大出力1000トークン、要求ごとのHTTP期限45秒。
- 4条件×4観測ケース×3反復＝48測定。別途、各入力1回のウォームアップ16要求。
  条件順は反復ごとの固定乱数で変更。ゲーム操作は送っていない。

4条件は、現行形式/根拠付き形式 × 全体画像/全体＋部分拡大。
根拠付き形式は指示文を変更し、各対象へrole_evidenceとunverifiedを加えた複合変更。
部分拡大は固定の重なり付き4分割を一枚に並べ、元画像とともに与えた。
変化箇所だけを抽出する拡大やSoMの部品マークは、今回の比較には含めない。

## 初見の結果

秒数は各ゲーム3反復の中央値を取り、3ゲームで平均した値。
事実への言及は各画面に事前設定した6項目の平均。Codexが原画像と照合した暫定採点であり、
独立した人手評価・盲検評価ではない。名称の種類や説明の長さは得点にしない。

|条件|事実への言及 /6|矛盾する位置・外観記述 /応答|秒|対象の概念参照が整合|
|---|---:|---:|---:|---:|
|現行形式・全体|1.78|0.11|6.90|9/9|
|現行形式・部分拡大|2.00|0.44|7.39|9/9|
|根拠付き形式・全体|2.56|0.78|8.79|9/9|
|根拠付き形式・部分拡大|1.89|1.44|14.13|7/9|

6項目は特定の部品と関係への言及であり、網羅的な認識精度ではない。
色だけを列挙し、指定した位置・隣接関係を述べない場合はその項目を加点しない。
事実への言及と誤った記述を別に数えるため、長い応答では両方が増え得る。
誤記数には、近似的な色の呼び方や未検証の役割名そのものを加算せず、後者は個別レビューに記載した。

### vc33

現行形式に部分拡大を加えると、上端の帯、中央の黒帯、下方の黄色と暗色の組への言及が3/3回で得られた。
ただし対象はpixel grid一件のままで、部品の役割を把握できたという結果ではない。

根拠付き形式では黒帯・黄・青を分けるが、「青が盤面の右上隅」「黒帯が24〜40の範囲」といった誤記が増えた。
部分拡大との併用でもこの誤記は解消せず、上端帯や下方の別の黄色を見落とした。

### ls20

根拠付き形式・全体では橙青の部品への言及が増えたが、それをExit、上部の図形をPortalと命名した。
名称を変えることと役割を確かめることは別で、初見の画素から裏付けられてはいない。
左下の青い図形を含む全体の対応は捉えられなかった。

根拠付き形式・部分拡大の2/3回は、宣言したconceptsにないmap_layout/crosshairをtargetsで参照した。
JSON Schemaは通るが、現行ランタイムの概念参照検証なら受理できない。
このため、形式的なJSON成功率だけを改善の根拠にしない。

### ft09

現行形式・部分拡大は、ホストの拡大表示の重なりを盤面のoverlapping quadrantsとして説明した。
根拠付き形式との併用は、中央の複合タイルと周りの色タイルを混同した。
いずれも右下の枠、他のパネルとの色配置の差を捉えられなかった。

## 操作前後の比較

実測では橙青部品が5画素上へ移動し、白い十字と上部の青い図形は不変。
下端の黄色い帯は1列、2画素だけ減少した。差分は計52画素。

**4条件×3反復の12回答すべてで、動いた橙青部品の同定と白い十字の役割訂正に失敗した。**
現行形式はほぼ以前の理解を再掲した。根拠付き形式は、白い十字について
「以前の位置から動いた」をrole_evidenceへ追加し、部分拡大併用では帯が不変だと誤記した。
根拠欄の追加だけで証拠に基づく認識へ変わるとはいえない。

この比較は、誤った過去理解を共通に与える訂正試験でもある。
入力から過去理解を外す条件は未実施のため、視覚比較能力と過去の記述への依存の寄与はまだ分離できない。

## 採否と次の比較

根拠付き形式と固定4分割の一括導入は見送る。初見の時間は約2.05倍で、訂正性能は改善していない。
部分拡大単独のvc33での局所的な改善は、次の実験の手掛かりとして残す。

次は、過去の意味づけを一旦外して「どの色・形がどちらへ動いたか」だけを答えさせる比較が適切。
同じ画像のまま過去理解の有無を切り替え、その後に変化領域と不変の注目対象を別々に並べた局所比較を試す。
この順序なら、入力の見せ方と過去説明への依存を分けて調べられる。
ここで画素レベルの対応付けも改善しなければ、同じ評価集合で視覚モデル・量子化条件の比較へ進む。

本体への反映や実ゲームでの攻略比較は今回行っていない。
開発用3ゲーム・1つの操作前後だけの結果であり、他ゲームへの一般化と独立した人手採点は未実施。
KVキャッシュがある固定入力再生なので、所要時間を本番の毎手の速度として外挿しない。
