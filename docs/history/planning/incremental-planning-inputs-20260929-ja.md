## 比較方法

基準の質問は `What should you do next?`。主比較にはシステムメッセージを付けず、簡単な結果提出ツールだけを共通に使う。`status=act/need_information`と`next_step`を必須にし、対象説明・候補IDは任意にした。CLICKや具体的な対象を必ず提案する制約はない。さらに、ツールもない文字どおり質問だけの自由文応答を3回取得する。

各要求は独立しており、前の応答を次の履歴へ追加しない。空の要求に以下の情報だけを明示的に追加する。

| 記号 | 入力 | 境界 |
|---|---|---|
| I | 現在画像1枚 | 過去画像なし。保存要求内の表示用画像をそのまま使用 |
| C | 現在候補85件のID・bbox・色ID、色名表 | 過去対象との対応、追跡ID、測定履歴、SAM実行情報は除外 |
| F | 前回の実操作・座標・受付・変化の実測 | 予測文・モデルの評価・次の問いを含めない |
| P | 過去計画の基準状態・期待効果・対象説明・予定操作 | 実測結果は含めない |
| K | 保存された長期知識 | 肯定形のclaim、contradictedのstatus、出典情報もそのまま |
| L | 過去対象から現在候補への対応情報 | Cがない条件では、現在候補の意味を解決する情報はない |

主比較は空・単独6条件・2種類の全15組・全種類・全種類から1種類ずつ外す6条件の29条件。2履歴×3回で174要求。各反復内の要求順を固定乱数で混ぜた。モデルは元と同じQwen3-VL-4B Q4_K_M、temperature=0、max_tokens=1000。

別に、**元の完全なuser入力を固定**して、元／簡単なsystem指示×元／簡単な出力schemaの4条件を比較する。2履歴×3回で24要求。ツール名を変える際は、system内の提出先名だけ新しい名前へ合わせる。これは主比較とは入力の構造や残存情報も違うため、主比較との間の差を指示文だけの効果とは解釈しない。

以上と自由文3要求で、最初の比較は201要求になる。

## 探索的な追加比較

最初の比較の途中で得た結果に基づき、Pの予定操作と説明文、Fの操作と結果を分ける。加えて、I+Fの実測を過去形の一文で表す条件、I+Kの知識を限定的な否定観測へ書き換える条件、I+C+F、I+C+Fにゲーム探索・利用可能なCLICK・過去結果の利用を明示する条件を比較する。8条件×2履歴×3回の48要求。

これは最初から独立に事前登録した確認試験ではなく、探索的な追試である。知識の書き換えでは文言・status・出典の提示もまとめて変わるため、否定語一語の効果とは扱わない。

## 結果

**計249要求が完了し、通信・解析エラー0件。構造化応答246件すべてが各条件のschemaを満たした。** 自由文3件はschema評価の対象外。保存要求249件を許可リストから再構成した要求と照合し、一致を確認した。通常ランタイムは変更していない。

主な結果は次のとおり。以下の「6回」は2履歴×3反復を合計した要求数であり、6つの独立した盤面ではない。特にI、Cだけの要求は2履歴間でも同一である。

| 入力 | 出力の観察 |
|---|---|
| 質問だけ | 簡単なschemaあり6/6、自由文3/3で情報不足を表明 |
| I：画像だけ | 6/6で赤い四角のクリックを提案。正しい位置・有効な操作とは確認していない |
| C：物体候補だけ | 6/6で対象を特定するための追加情報を要求 |
| P：過去計画だけ | 6/6で過去と同じ白い四角の説明を使ってクリックを提案 |
| K：長期知識だけ | 5/6で白い四角のクリックを提案。残り1件も白い四角の追加調査を求めるが、statusはneed_information |
| F：実操作＋無変化の実測だけ | 6/6で前回の座標を再提案。1巡目は(15,15)、2巡目は(47,15) |
| I+F | 6/6で前回の座標を再提案 |
| I+C | 6/6で「白い画素」を選ぶ。候補IDはf3t31が5件、f3t33が1件 |
| C+F | 6/6でf3t43を「白い四角」としてクリック提案。ただしその候補はオレンジ色の最下段の線 |
| 全6種類 | 6/6で白い四角のクリックを提案 |
| 全種類から1種類を除去 | 6条件×6回の36/36で白い四角のクリックを提案 |

**過去情報がなくてもI+Cで白い画素を選ぶ一方、Iだけでは赤い四角になる。** したがって、物体候補を追加すると対象説明が変わることを、この固定入力では再現できた。ただしf3t31は白い領域、f3t33は青い領域で、説明とIDの不一致も残る。前回と同じ白い四角を選んだことや同じ座標をクリックしたことまでは示さない。

Lの効果も対象説明とIDで異なる。1巡目の全入力ではf3t55が3/3、Lを外すとf3t23が3/3だったが、どちらも説明は白い四角。2巡目はLを外してもf3t23が3/3で維持された。全入力での候補は、どちらも白い四角という説明と一致していない。

### さらに小さくした構成

| 追加比較 | 結果 |
|---|---|
| 過去の予定操作だけ（P_action） | 白い四角のクリック6/6 |
| 過去の基準状態・対象説明だけ。予定操作なし（P_description） | 白い四角のクリック6/6 |
| 前回の実操作・座標だけ。結果なし（F_action） | 前回と同じ座標をクリック提案6/6 |
| 無変化の実測結果だけ。操作・座標なし（F_result） | 6/6とも具体的対象を選ばず「次の操作へ進む」などの一般論。statusはactなので、schema成功は行動可能性を保証しない |
| I+C+F | 前回と同じ座標をクリック提案6/6 |
| I+C+Fにゲーム探索・CLICK・前回結果の利用を明示 | 前回と同じ座標をクリック提案6/6 |

この粒度では、**予定操作そのものを残さなくても、過去の対象説明だけで同じ白い四角の提案が再現する。** また、白い四角という説明がなくても、前回の実座標だけで座標反復を再現する。反復に結び付く小さな構成は一つではない。

### 実測や知識を文章に直すとどうなるか

I+Fの履歴を、座標を含む次の一文へ置き換えた。

> The previous CLICK at x=15, y=15 was acknowledged. The before and after boards were identical: zero cells changed in that observed interval.

2巡目は座標をx=47, y=15とした。クリックが過去に行われ、結果が無変化だったという情報は保持しているが、JSONの各項目を並べる構成から過去形の文章へ表現を変えている。

| 比較 | 同じ座標のクリック提案 | 追加観察を要求 |
|---|---:|---:|
| I+構造化したF | 6/6 | 0/6 |
| I+過去形の実測文 | 0/6 | 6/6 |

Kも、肯定形のclaimとcontradictedの組み合わせから「その対象を試したクリックでは可視変化なし。他条件で反応するかは不明」という観測表現へ変え、Iと組み合わせた。元のI+Kは6/6で白い四角のクリック、新しい表現では6/6で他の白い四角などの追加調査を求めた。

このKの対象説明は元のモデル記述を引き継いでおり、実際のクリック対象との一致をホストが保証したものではない。書き換えは提示表現の比較であり、その知識を検証済みの事実へ昇格させたものではない。

これらは**再クリックを出さなくなったという局所的な改善**だが、6/6がneed_informationになり、有効な別操作を生成できたわけではない。既に画像を渡していても再観察を求めるので、そのまま採用すると別の停滞を作る可能性がある。知識の書き換え後も白い四角への注目は残る。

### 長い指示文・出力形式の影響

元の完全なuser入力に対し、元／簡単な指示×元／簡単なschemaの4条件すべてで、各6/6が白い四角のクリックだった（合計24/24）。この場面では、長いsystem指示や元の複雑なschemaが反復に必須とはいえない。もちろん、それらが他の状況でも無害だという検証ではない。

## 次に修正する候補

優先対象は、ステート数の削減より**実測履歴・過去仮説を次行動へ反映する入力と出力の接続**である。少量の情報でも、過去の記述・操作を次の操作として再出力できてしまうため、情報量だけでは説明できない。

1. 過去操作と実測結果を一つの完了済みの事実として渡す。過去の対象説明・肯定形の期待効果を現在の推奨対象のように提示しない。まず同じ工程のまま表現だけを比較する。
2. 結果を受けて「別の対象を試す」「条件を変えて再試行する」「本当に不足する観測を指定する」のどれを選んだのかを実操作に結び付ける。再理解・再観察への移動だけで改善扱いにしない。
3. 対象説明・候補ID・照準位置の一致を別に確認する。C+Fのオレンジ線を白い四角とする誤りのように、候補IDが存在するだけでは不十分。

**通常設定への採用や成功率の改善は未確認。** 今回は入力依存を比較する段階までとし、有効な別操作を選べた構成が確認できていないため、ライブゲームでの改善を主張しない。

## 解釈の範囲

目的は「白い領域へ注目する」「以前の座標を再提案する」「現在候補を正しく指定する」を分けて調べること。白という語が出たことと、以前と同じ物体への照準・クリックは同じではない。自由文の根拠説明も内部思考の計測ではない。

ここでいう小さな構成は、この質問・モデル・書式・選んだ場面に対するもの。全組み合わせを調べておらず、入力の単語や画素まで最小化してもいない。3回の反復は局所的な再現性の確認であり、未知のゲームでの精度や成功率を推定するサンプルではない。情報不足の条件では、回答が変わっても改善とは判断しない。

今回の設計は、判断を保つ小さな入力集合を探す[Sufficient Input Subsets（Carterら、2019）](https://proceedings.mlr.press/v89/carter19a.html)、周辺条件に対する判断の安定性を扱う[Anchors（Ribeiroら、2018）](https://ojs.aaai.org/index.php/AAAI/article/view/11491)、入力の組み合わせを考慮する[SHAP（Lundberg・Lee、2017）](https://arxiv.org/abs/1705.07874)を参考にした。各手法をそのまま実装したものでも、attentionの可視化でもない。
